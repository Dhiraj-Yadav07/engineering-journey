# GCP IAM Console

## Objective

Explore GCP IAM and understand principals, roles, permissions, and policies.

## IAM Model

Principal
    ↓
IAM Policy
    ↓
Role
    ↓
Permissions
    ↓
Resource

## What I Explored

* IAM Console
* Principals and access
* Project-level IAM policies
* Basic and predefined roles
* Permissions
* Service accounts

## Key Takeaways

* **Principal** — Identity requesting access.
* **Role** — Collection of permissions.
* **Permission** — Specific operation allowed on a resource.
* **IAM Policy** — Binds principals to roles.
* IAM policies can be inherited through the resource hierarchy.
* Prefer least-privilege roles over broad access.
