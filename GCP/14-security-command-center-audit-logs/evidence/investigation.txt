9. Investigation conclusion.

The lab successfully demonstrated an end-to-end detection pipeline. A BigQuery
query-result extraction to Google Drive generated a Cloud Audit Logs DATA_ACCESS
event containing BigQueryAuditMetadata. Event Threat Detection analyzed the
activity and generated an ACTIVE, LOW-severity Security Command Center threat
finding. The finding correlated the principal, affected BigQuery table,
Cloud Logging entry, Google Drive destination, exfiltrated byte count,
BigQuery job, and MITRE ATT&CK exfiltration classification.
